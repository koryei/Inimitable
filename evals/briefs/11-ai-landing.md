# Landing page: an AI product, built to feel premium

Build the landing page for **Fathom**, an assistant that reads a company's cloud bills and explains where the money goes. Facts you may use and nothing else:

- It connects read-only to AWS, Google Cloud and Azure billing exports.
- Plain-English answers: "Why did our bill go up in October?"
- It flags unusual spend within a day and links to the cost line responsible.
- Setup takes about ten minutes; no agents installed in your infrastructure.
- Free for one cloud account; Team plan is $49 per month per cloud account.
- Made in Amsterdam, founded 2025. SOC 2 is not yet complete: do not claim it.

Do not invent customer names, logos, counts, percentages, savings figures or benchmarks. Any example screen or number you draw must be marked as an example. One primary action: connect a billing export.

The page will be judged by a designer on how premium it feels: atmosphere, typography, motion on entrance and scroll, how every button and link answers the mouse, and how it looks on a phone. Output ONE self-contained HTML file (inline CSS and JS, no network). Fonts: system stacks only unless you have local font files.
