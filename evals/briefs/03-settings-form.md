# Settings and a form

Build the **Notifications** settings page for a project-management web app called **Plot**. A signed-in user can:

- Choose delivery per channel (email, mobile push, Slack) for: mentions, assigned to me, due soon, weekly summary.
- Set quiet hours (start, end, days of the week).
- Turn a daily digest on or off and pick its time.
- Connect Slack (currently not connected).
- Delete all notification history (destructive).

Include saving behaviour and realistic states: unsaved changes, saved, one validation problem (quiet hours end before start), and the Slack not-connected state.
