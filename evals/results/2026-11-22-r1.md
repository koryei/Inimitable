# Round 1, 22 November 2026

Six briefs, one baseline agent (no skill) and one skilled agent (told to read `SKILL.md`, follow the run and use the scripts) per brief. Same model. Skilled version of the skill: 0.2.0.

## Mechanical score (out of 100)

| Brief | Baseline | Skilled |
| --- | --- | --- |
| 01 Landing | 61 | 94 |
| 02 Dashboard | 51 | 89 |
| 03 Settings form | 42 | 90 |
| 04 Pricing | 67 | 96 |
| 05 Sign-up and first run | 75 | 96 |
| 06 Docs | 43 | 94 |
| **Mean** | **56.5** | **93.2** |

Baseline pages averaged 2 kinds of tell and 10 accessibility or state problems each, mostly touch targets and contrast. Skilled pages had none of either.

## Blind visual judgement

Judged from 1440 px renders, A against B, before opening the key.

| Brief | Winner | Why |
| --- | --- | --- |
| 01 Landing | **Baseline** | Topographic-line background and a larger idea made it far more distinctive. The skilled page was clean and honest but plain. The baseline also carried tells (italic accent word, mono eyebrow). |
| 02 Dashboard | Skilled | One clear star (the critical incident), calmer, one accent, better chart. |
| 03 Settings | Skilled | Checkbox matrix, a 24-hour quiet-hours strip as the moment, clearer layout. |
| 04 Pricing | Skilled | Plans and calls to action visible on the first screen; baseline spent the first screen on a centred hero with an italic accent word. Both converged on the same warm-paper-and-serif look. |
| 05 Sign-up | **Baseline** | A drawn cairn of stones gave it character; the skilled page used flat ellipses. |
| 06 Docs | Skilled | Quieter, better measure, no invented metadata. The baseline had uppercase labels, a glowing callout, a "New" badge and a made-up version number. |

**Result:** skilled won 4 of 6. It was better on hygiene, accessibility, hierarchy and honesty in every brief. It lost on **visual richness and distinctiveness** where a page needed an illustration or a memorable motif.

## Findings, and what changed

| Finding | Source | Change |
| --- | --- | --- |
| Skilled pages are clean but plain on expressive surfaces; baseline won by drawing something | judging | New `references/visual-craft.md` and `assets/recipes/`: how to build the one rich moment in code (contour lines, layered stones, dot fields, grain) without tells; `build-new.md` and `landing.md` now require a world motif |
| No path when nobody can answer the direction question | 5 of 6 agents | Read and Direction steps: if no person is available, state the direction and assumptions and proceed |
| `check.mjs` read backgrounds only from ancestors, so a sibling behind text caused a false 1.10:1 | pricing agent | Backdrop is now found by hit-testing the stack at the text |
| `check.mjs` counted hidden `h1` elements | sign-up agent | Counts visible headings only |
| `shoot.mjs` could not set state, scroll or wait | 5 of 6 agents | New `--eval`, `--wait`, `--scheme` and `--slices` options |
| `drift.mjs` flagged a display serif plus mono as three families, semantic and syntax colours as hue drift, and inverted surfaces as 7 text colours | 4 agents | Rules allow one partner plus a mono for data; flags now exclude semantic and code colours and group text colours per surface |
| House rules disagreed on warm versus graphite neutrals for apps | settings agent | Clarified: low-saturation warm and ink ramps are fine for apps |
| No guidance for 2560 px, or that CSS zoom breaks `dvh` | dashboard, sign-up, landing | Big-screen section in house rules: scale root size, use rem and `lvh` |
| No guidance for choosing fonts in a file with no network | sign-up agent | System stacks added to house rules |
| Headline "two lines or fewer at every width" impossible at 320 px | landing agent | Rule is two lines at desktop, three at most on small phones |

Round 2 re-runs the landing, sign-up and pricing briefs with the updated skill.
