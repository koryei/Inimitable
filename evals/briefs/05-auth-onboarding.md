# Sign-up and first run

Build a sign-up screen and the first step of onboarding (a single page showing both states, switchable) for **Cairn**, a habit tracker. Sign-up: email and password with a Google option, a terms note. First step after sign-up: pick up to three habits to start with from a list of ten (Read, Walk, Stretch, Water, Sleep before 11, No phone in bed, Journal, Cook at home, Practise guitar, Call a friend), choose a daily reminder time or skip, then start. Include the error state for an email already in use, and the empty state of "no habits picked yet".
