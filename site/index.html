Design that looks decided.

Inimitable is a skill for coding agents. It builds and repairs interfaces, opens them in a real browser at four sizes, measures them and fixes what it finds before it shows you.

What it does

What changes between request and result.

An agent usually gives you the first screen it can produce. Inimitable makes it decide first, then check its own work.

Looks before it shows

It renders the real screen at 320, 390, 1440 and 2560 px, hovers every control and fixes what it sees, for up to three rounds.

9

One fixed run

Read, decide, build, gate, look, report. The same nine steps for a new screen and a shipped one.

  • Font sizes, weights, radii and spacing counted
  • Contrast read from rendered pixels
  • Tells found by name

Measures, doesn’t guess

Tells are the marks of machine-made UI: the purple gradient, the glowing badge, the emoji label.

Respects your rules

Decides, then asks

Reports plainly

The run

One fixed run for every request.

Nine steps, in order. Each names the file it reads, so a new screen and a shipped one get the same care.

  1. 01

    Read

    Finds your design rules, watches the screens run and measures the drift.

  2. 02

    Decide the mode

    Persuade, Operate, Read, Experience or Terminal: what the person is doing here.

  3. 03

    Fix the direction

    Five lines on how it should feel and what it must never look like.

  4. 04

    Branch

    Repair a screen layer by layer, or build a new one around one star.

  5. 05

    Build

    One section at a time, from your own components, with every state designed.

  6. 06

    Gate

    Your lint and tests, then measured contrast, target size and tells.

  7. 07

    Look

    Renders at four widths, hovers every control and fixes what shows, for up to three rounds.

  8. 08

    Report

    Short and honest, with real before and after numbers.

  9. 09

    Log

    Lessons go into your project’s notes. The skill never edits itself.

Install

One command, no keys.

You need Node 22 or newer and an installed Chrome, Edge or Chromium. Terminal screenshots also use Python 3. There are no packages to install and no API keys.

Any agent

npx skills add koryei/Inimitable

Installs into Claude Code, Codex, Cursor and the other agents you have. Add -g to install for every project. It is listed on skills.sh.

From a clone

git clone https://github.com/koryei/Inimitable.git && cd Inimitable && ./install.sh

Links the folder into ~/.claude/skills/inimitable, so git pull updates it.

Questions

Short answers.

Will it override my brand?

No. Your own rules win over everything in the skill. If a device is part of your brand, say so once and it is kept.

Does it need an image generator?

No. It draws visuals in code. Where an image would help, it writes the prompt and leaves a labelled slot.

Does it work on existing apps?

Yes, that is the main use. It repairs a screen in your own stack and components, and leaves your product, content and section order alone.

What can’t it do?

It can’t make photographs, and it doesn’t invent facts: every label it draws is true or marked as an example. The native mobile rules are written but not yet tested on a device.

What does it cost?

Nothing to run: no services and no keys. It uses the tokens your agent already spends.

Install it once, then ask for a screen.

It reads your project, builds the screen and checks its own work before you see it.
