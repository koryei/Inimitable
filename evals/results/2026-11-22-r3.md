## Visual judgement

The answer key was printed in the same command as the scores, so this round was **not blind**. Treat it as a careful read, not a clean test.

| Brief | Winner | Why |
| --- | --- | --- |
| 09 | **Skilled** | The hero is the product's own idea made visible: an example message ("Meet at the east gate, 9pm") in dotted letters that dissolves into noise, with a dashed "encrypted here" line, numbered pins and a legend, all marked as an illustration. Light instrument direction, corner brackets, `//` labels, one bracketed phrase, a stat strip. The baseline was polished and conventional: a serif headline with an italic second line, a card showing plaintext turning into ciphertext. |
| 10 | **Skilled, narrowly** | A halftone M.2 card at true proportions with three callouts (`[01]` compute, `[02]` memory, `[03]` connector), each marked "Example placement", a millimetre ruler and corner brackets. Honest and in the reference style. The baseline drew a richer, more colourful circuit board and was attractive; the skilled page was more distinctive and more faithful to the brief's no-invention rule. |

**Result:** skilled won both. Across three rounds it has won 9 of 12 comparisons, with mean mechanical score 96 against 62 for baseline.

Both skilled agents chose **Instrument light** on their own, for a reason worth keeping: almost every security or AI-chip page is dark with a green or purple glow, and a paper-and-ink datasheet look sets the product apart.

## Findings, and what changed

| Finding | Source | Change |
| --- | --- | --- |
| `dotify.mjs` crashed on a bare `.svg` | chip agent | Bare SVGs and photos are wrapped in a real temp file (a `data:` page cannot open `file://` images, which had also broken photos) |
| Hex and halftone output was 200 to 290 KB | both agents | Dots now share round-capped strokes by size class: about a third the size |
| No way to make a message or claim break into noise | messaging agent | `dissolve()` in `dither.mjs` |
| The kit was in px, so it did not scale on big screens | messaging agent | `instrument.css` is in rem, with `html.inst-scale` for big screens |
| Nothing on how to treat actions with no backend, or missing store links | both agents | `build.md` section on placeholders and honest preview states, listed in the report |
| No fonts named for the no-web-font case | chip agent | `directions.md` gives a pairing per look |
| `dotify` crop and height behaviour surprised the agent | chip agent | Fixed the height floor; documented the margin and the HTML-file route for text |
