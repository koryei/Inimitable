# Round 2, 22 November 2026

After the round 1 changes (visual-craft guide and recipes, tool fixes, non-interactive path, clarified rules). Skilled agents re-ran landing, pricing and sign-up; a new brief, **08 Portfolio** (an Experience surface with no photographs), was run with both arms to check the skill is not just fitted to the first six. Baselines for 01, 04 and 05 are the round 1 baselines.

## Blind visual judgement

| Brief | Winner | Why |
| --- | --- | --- |
| 01 Landing | Skilled (slight) | Contour field plus a card pinned to it: the same idea as the baseline, with better restraint and no italic accent or mono eyebrow. The baseline's headline was more dramatic. |
| 04 Pricing | Skilled | A paid invoice as the hero object with a halftone field behind it, plans visible on the first screen. The baseline spent the first screen on a centred headline. |
| 05 Sign-up | Baseline (slight) | Its five-stone cairn with lichen was richer than the skilled page's three smooth stones, which read as stacked discs. The skilled interface was cleaner and its state switcher better placed. |
| 08 Portfolio | **Skilled, clearly** | Three vessels drawn to scale beside a centimetre ruler, with throwing rings and a left light, against a baseline of only large type with an italic accent. |

**Result:** skilled won 3 of 4 on the new run, and 7 of 10 across both rounds. Mean mechanical score 98.5 against 72.5. The rich-moment guidance worked: in the one brief with no obvious illustration (portfolio), the agent built a generator for turned vessels and the page became the strongest of the set.

## Findings, and what changed

| Finding | Source | Change |
| --- | --- | --- |
| Contour output was thousands of separate segments, too heavy for a full-page field | landing agent | `contours.mjs` stitches segments into polylines |
| Nothing for turned objects (pottery, glass, lathe work) | portfolio agent | New `revolve.mjs` recipe: a profile curve to a lit, ringed vessel |
| Stones looked like stacked discs next to a hand-built illustration | judging, sign-up | `shapes.mjs` gains flat contact bases, speckle and per-stone offsets |
| `grain.css` was invisible on dark panels | sign-up agent | Dark variant added |
| `check.mjs` still gave a false contrast flag when a pseudo-element draws the backdrop | pricing agent | Backdrop sampled from rendered pixels |
| Serif for large figures versus "serif for headlines only" | pricing agent | Rule says display serif covers large headline-size text and figures |
| Overlap between the per-section loop and the three look rounds | portfolio agent | `look.md` and `build.md` say which is which |
| Page-state switchers and interaction states not covered | sign-up and pricing agents | `look.md` covers previewing states, with a pattern for a single-page switcher |
| Facts a page needs but the brief does not give | pricing agent | `build-new.md`: leave it out or mark it, never invent |
| Doc commands used `sed -i`, which differs on macOS | landing agent | Not an issue in the skill's own files; noted in `CONTRIBUTING.md` |
