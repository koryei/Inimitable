A design skill for coding agents

Design that looks decided.

Inimitable builds and repairs interfaces until they look made on purpose. Then it opens them in a real browser at four sizes, measures them, and fixes what it finds before showing you.

What it does

Agents make screens that work and look like everything else. This changes what happens between your request and the result.

[01]

Respects what you already have

Your brand guide, tokens and design notes outrank its own taste. It never repaints a product in a style that is not yours.

[02]

Measures instead of guessing

Scripts count the font sizes, radii, colours and spacing in use, find the tells of machine-made UI, and read contrast from the rendered pixels.

[03]

Looks before it shows

It renders the real screen at 320, 390, 1440 and 2560 px and fixes up to three rounds of problems, so you only give taste feedback.

[04]

Knows why, and how to be memorable

It reasons from principles of perception and feedback, and it draws one rich moment in code: contours, vessels, dithered objects, annotation.

The run

One fixed run for every request.

  1. [01]ReadFinds your design rules, sees the screens running, measures the drift.
  2. [02]Decide the modePersuade, Operate, Read, Experience or Terminal: what the person is doing here.
  3. [03]Fix the directionFive lines on what it should feel like and what it must never look like.
  4. [04]BranchRepair a screen layer by layer, or build a new one around one star.
  5. [05]BuildOne section at a time, from your own components, with every state designed.
  6. [06]GateYour lint and tests, then measured contrast, targets and tell checks.
  7. [07]LookRenders at four widths, fixes what shows, up to three rounds.
  8. [08]ReportShort and honest, with real before and after numbers.
  9. [09]LogLessons go into your project’s notes. The skill never changes itself.

The tools

Plain Node scripts. No dependencies. Run them yourself on any page.

CommandWhat it does
shoot.mjsScreenshots at 320, 390, 1440 and 2560 px. Flags sideways scrolling and console errors. Can set a page state first.
drift.mjsCounts the font sizes, weights, radii, colours and spacing values in use, and flags drift. Before and after.
signs.mjsFinds machine-made tells in the rendered page: hue gradients, glows, emoji, hype words, unverified claims.
check.mjsWCAG contrast read from rendered pixels, touch targets, small text, names, focus styles, layout shift.
score.mjsRuns every check and prints one score out of 100 with what cost points.
dotify.mjsTurns any image or drawn SVG into dither, halftone, hex dots or ASCII for a hero object.
term-shot.mjsRuns a terminal program at a set width in a real pseudo-terminal and captures text and an image.

Install

One command.

Any agent

npx skills add koryei/Inimitable

Installs into Claude Code, Codex, Cursor and the other agents you have. Add -g for every project. Listed on skills.sh.

From a clone

git clone https://github.com/koryei/Inimitable.git && cd Inimitable && ./install.sh

Links the folder into ~/.claude/skills/inimitable so git pull updates it.

Needs Node 22 or newer and an installed Chrome, Edge or Chromium. Terminal screenshots also use Python 3. No packages and no API keys.

Questions

Short answers.

Will it override my brand?

No. Your own rules win over everything in the skill. Where a device is part of your brand, say so once and it is kept.

Does it need an image generator?

No. It draws visuals in code. Where an image would help it writes the prompt and leaves a labelled slot.

Does it work on existing apps?

Yes, that is the main use. It repairs a screen in your own stack and components and leaves your product, content and section order alone.

What does it not do?

It cannot make photographs, and it does not invent facts: labels it draws are true or marked as examples. Native mobile rules are written but not yet tested on a device.

What does it cost?

Nothing to run: no services, no keys. It uses the tokens your agent already spends.
